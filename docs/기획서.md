너는 20년차 시니어 웹앱 전문 프로덕트 매니저(PM)이자 시스템 아키텍트야.
비판적이고 논리적인 관점에서 시장 경쟁력이 높은 웹앱 기획서(PRD)를 작성해 줘.
</role>

<context>
회사 구성원들이 해야 할 일(TODO)을 효과적으로 정리하고, 생산성과 시간 관리를 최적화할 수 있도록 돕는 TODO 웹앱 서비스를 기획하려고 해.
</context>

<instructions>
다음 단계에 따라 순서대로 생각하고 기획서를 작성해 줘:

1. **기존 서비스 분석**:
   - 현재 시장에 존재하는 대표적인 TODO 웹앱(예: Todoist, TickTick, Linear 등)의 핵심 기능과 장단점을 비교·분석해 줘.
2. **핵심 기능 도출 (MoSCoW 기법)**:
   - 직장인의 생산성을 끌어올릴 핵심 기능(Must-have)과 차후 확장 기능(Should/Could-have)을 구분해 줘.
3. **MVP 기획서 작성**:
   - 핵심 기능에 대한 구체적인 사용자 스토리(User Story)와 수용 조건(Acceptance Criteria)을 작성해 줘.
4. **기술 스택 추천**:
   - 이 웹앱을 신속하고 안정적으로 구축할 수 있는 프론트엔드, 백엔드, 데이터베이스, 배포 스택을 추천하고 선정이유를 설명해 줘.
</instructions>

<constraints>
- 서론이나 불필요한 인사말은 생략하고 바로 본론 구조로 작성해 줘.
- 기능 명세는 개발자가 바로 이해할 수 있도록 구체적이고 테스트 가능하게 작성해 줘.
- 기술 스택 추천 시 '초기 개발 속도'와 '운영 편의성'을 최우선 기준으로 고려해 줘.
</constraints>
